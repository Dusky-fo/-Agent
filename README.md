## 启动与第一次使用

双击本工程 `start.bat`，同意 Windows UAC。启动阶段后只保留本工程的管理员桌面宿主进程；源码模式在任务管理器显示 `pythonw.exe`。依赖使用本工程 `.venv`。不重启其他程序，不自动点击或重启被监控目标。

1. 总览显示版本1.0、源码修订、真实待办及QQ/监控入口。先添加本地监控即可使用，不强制接QQ。程序列表整行/空格选择，同名实例统一；采集失败、陈旧状态显示未知。
2. 设置→QQ接入→快速接入，用户自行在官方平台创建机器人，填AppID/AppSecret、选择沙箱/正式环境，点保存并连接。高级手动配置保留原表单；仅保存不重连。
3. 连接后点开始绑定（2分钟），本人QQ发“开启”，在本机核对手机同一配对码并确认一次，自动保存身份和订阅，不用抄OpenID；陌生请求不会自动授权。
4. 设置→文件夹权限集中显示五种独立用途。选择目录、只开启所需用途并确认，默认不开放桌面。仅本机资料会限制QQ取文件；接收/管理授权不自动共享。
5. QQ说“把测试文件发给我”，唯一匹配回“发送”，多个先选编号。当前授权对话收件；2分钟、内容校验、撤权、去重仍保留。手机真正收到后，可对唯一待确认文件说“收到了”；多项用“收到任务 编号”。
6. 监控页配置文件/日志观察及异常规则，默认关闭；文件页配置QQ附件接收并明确“接收”才落盘。文件→本机整理提供搜索、预览、改名/同卷移动/整理、文字转换、文本编辑和恢复。
7. 记录页先在完整保留范围筛选，再每页30条显示，提供状态/操作/日期/任务编号及文件名搜索、上一页下一页，默认优先需处理项，用结果句区分执行完成、平台接受与用户收到；告警事件由同页进入。帮助可搜索，错误有就地提示及处理入口。
8. 工具页保留鼠标、网页、游戏适配插件。鼠标同按钮/同自定义快捷键启停，未配置不启用，启动软件不点击。外观保留六套皮肤。

七个一级入口：总览、监控、文件、记录、工具、设置、帮助。设置六张卡；返回QQ页保留未保存输入，配置小窗有保存/放弃/继续编辑；退出和切换目录复用检查，保存中继续输入不会被旧提交标为已保存。后台工作按资源隔离，帮助与不冲突操作仍可用；周期状态后台采集，隐藏任务表不重建。

可选 `start_standard.bat` 普通权限启动，`start.bat` 仍保持用户要求的管理员默认；未新增开机启动。重复打开同一数据目录请求唤出已有窗口，不新起第二个核心，不能并行操作同一数据目录。
也可右键灵梭托盘图标，选择“以管理员身份重启”，并在 Windows UAC 窗口确认。先处理未保存内容；取消 UAC 时继续运行原实例。授权后正常退出原实例，新实例最多等待旧进程退出 120 秒再读取同一数据目录；等待失败停止新实例，不强制结束进程。只重启灵梭，不重启或结束被监控程序。

## QQ 的实际边界

官方发送文档已标注主动推送自2025-04-21停止。不能承诺离线/任意时刻推送手机告警。本机先记录并入队，有已授权用户近期消息时才尝试被动回复。本版仅私聊，按官方C2C说明使用60分钟、每条用户消息共5个回复序号；命令预占、文件与队列继续分配，当前用户请求优先。账号实际配额和时效仍待验收；无上下文显示等待，可先向机器人发“状态”。待发超过24小时失效。同类待发告警合并数量并保留最近文字；冷却窗口后新事件可再次入队。

上传使用官方富媒体分片接口，序号从1开始，分片及已知待就绪错误有限重试；最终消息不自动重复提交。只有返回消息标识才记“平台接受”，网络/服务响应不确定记“结果待核对”。这不等于手机收到。具体接口权限、沙箱/正式范围、签名URL和实际收发仍需账号验收，不支持群聊。

参考：[官方发送说明](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/server-inter/message/send-receive/send.md)、[官方协议DTO](https://github.com/tencent-connect/qqbot-agent-sdk/blob/main/src/qqbot_agent_sdk/dto.py)。这里只参考接口定义，没有接入该 SDK 的 Agent 能力。

## 授权范围与已支持的操作

| 范围 | 用途 | 是否默认开放 |
|---|---|---|
| QQ共享目录/实际Windows桌面 | QQ搜索、选择、确认发送 | 否 |
| 仅本机资料目录 | UTF-8文本编辑、备份，本机选择文字后可确认入通知队列 | 否；QQ文件接口排除 |
| 文件观察目录/指定日志 | 元数据轮询、日志新增文字规则 | 否 |
| QQ接收目录 | 授权对话明确回复后附件落盘 | 否 |
| 本机文件管理目录 | 搜索、同卷移动/重命名、按扩展名整理、文档输出/恢复 | 否；不授予QQ工具调用 |

程序凭据与数据库目录始终排除。目录联接、符号链接、网络路径不作为新服务范围。授权范围相互独立；授权目录或程序名变更会重新建立相关基线。

文件管理每次最多100文件、总量100MB，仅同一磁盘卷移动，不移动整个目录。预览5分钟有效；确认前校验文件内容，拒绝重名覆盖。保留原文件备份和恢复记录；目标后来修改、源位置冲突或权限撤销时拒绝自动恢复。中断可能部分完成，不宣称整批事务。备份上限512MB，达到上限在变更前阻止，不自动删除唯一恢复副本。恢复列表显示文件名、原目标详情及真实占用；仅已恢复且原位置内容未变的记录可在恢复页先预览再确认清理冗余备份；执行用Windows读取锁保护原文件，不能锁定或存在冲突就拒绝，未恢复的备份不会清理。

文档转换：UTF-8 TXT/MD→DOCX、DOCX→TXT、TXT/MD→HTML。输入≤5MB、DOCX解压总量≤20MB、输出≤10MB；文本或段落最多一万行/段。只转换文字，格式、图片和页眉脚注不保证保留；Markdown不渲染。不支持PDF/旧DOC/OCR，不启动Office。文本编辑≤1MB，保存前校验版本并备份。

目录观察采用有上限的轮询，默认3秒/5000文件/深度10层，可能漏掉扫描间隔内的瞬时变化。日志首次从末尾增量读取，UTF-8、每轮64KB、匹配行前4096字；支持常见轮转和截断，通知只包含命中次数/文件名，不复制旧日志或原始正文。受限正则不允许量词、分组、分支和反向引用。

异常规则检查已选择进程：每PID整机占比CPU、工作集内存、可见窗口响应及本轮曾观察到的程序持续退出。持续异常只报警一次，正常后记录恢复；未知暂停计时。不会启动、结束或自动重启程序。

## 任务、网页、插件与鼠标工具

任务保存编号/拥有者/状态/步骤/进度/结果/安全失败原因，支持协作取消和检查点超时。网络等待等当前请求返回，不能撤回已经提交的消息或已完成文件变更。退出后未完成任务记中断，不自动重跑。通知队列直接映射为N开头任务，避免生成第二套虚假状态。编号测试通知和文件支持人工收件确认，普通通知暂无无编号的收件确认。

网页搜索仍按明确点击打开Bing/百度。“工具 → 授权网页读取”：逐次确认完整公开HTTPS网址，一次性2分钟授权；GET≤1MB、文字前10000字，仅UTF-8。校验公共地址、固定DNS、TLS主机验证；拒绝内网、非443端口和重定向。不携带Cookie或本机文件，不执行脚本/页面指令/表单提交。没有登录网站和表单自动化。

统一工具协议见 `docs/工具与任务协议.md`：宿主指定身份/入口/权限，参数不能自授权限；支持1–10步固定编排，取消/失败不撤销先前步骤。当前没有图形化编排编辑器，也没有通用规划器或模型。

受信插件沿用现有清单、信任哈希、禁用与加载隔离；启用/导入内容变更需重启。普通Python插件具有宿主权限，管理员启动时同样具有管理员权限，声明与统一工具检查不是安全沙箱。可选彩虹岛适配仍独立，不默认加载，不操作游戏。

普通鼠标连点已移除，旧参数不读取，底层普通连点模式也被拒绝。图片识别点击独立保留，只在唯一图像匹配后点击；未设置图片、范围与启停键不能开始。先应用配置不会点击，再点开始是用户明确启动；同一按钮/快捷键停止，Esc与角落停止保留。关闭工具、修改参数或收起会解除启用。真实图像识别、输入与热键仍待另行授权验收。

## 数据与源码开发

AppSecret使用当前Windows账户DPAPI加密落盘，旧明文在应用加载时迁移；失败保留原文件并提示，换Windows账户不可解密时停用QQ、本地继续。它不能阻止同账户恶意代码或受信插件。默认 `%LOCALAPPDATA%\LingSuoBasic` 保存本项目配置、密钥、身份、队列、事件、任务和恢复备份。不要分享真实数据目录。任务详情可能包含文件名、路径和网页文字；不自动上传这些结果。首次使用不导入原LataleGuard配置，源码不依赖原工程绝对路径。

开发环境 Windows x64 / Python3.12（含Tk），只在新工程的独立环境安装：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --self-test --report work\native-selftest.json
```
