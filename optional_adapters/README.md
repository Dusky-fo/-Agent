# 独立可选适配与旧业务参考

此目录不进入基础发行包，也不会由核心扫描或自动加载。

`legacy_cherry` 是从原工程提取的独立可选包。旧动作层已使用包内兼容函数，不再读取旧工程配置、不依赖旧工程目录。清单目前仅注册读取目标状态的工具；旧动作实现保留在包内，未开放自动控制入口。

如以后明确需要使用此包：在独立环境安装它的可选依赖 numpy、Pillow、uiautomation、opencv-python、rapidocr-onnxruntime；将整个 `legacy_cherry` 放入数据目录的 `plugins`；将 `settings.example.json` 复制为 `settings.json`，指定自己的数据根目录；审查代码及权限后，在面板信任并启用，重启生效。

基础版不安装这些依赖。本次没有加载该动作模块、读取目标状态或操作任何第三方窗口；实机兼容性尚未验证。导入 Python 插件不是沙箱隔离。

`legacy_reference` 保存原命令路由、副本模块及游戏流程的源代码参考（`.py.txt`），用于后续专项适配。它们含旧业务上下文与未迁入的依赖，不能作为可运行插件。这些文件不是个人配置、日志或数据库。

游戏选角、WeGame 专用流程和副本报表没有在新基础核心中保留运行入口。没有通过隐藏名称将其留在基础包。
