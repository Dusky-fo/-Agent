# 灵梭 1.0：白话取文件、鼠标工具及窗口居中

源码已修改于 `G:\Ai\OH-WorkSpace\项目\灵梭Agent`。没有生成新 EXE 或压缩包，没有修改原 LataleGuard 工程或原环境、Render、模型或云端业务配置。

## 本次完成

### 文件发送减少操作

QQ 可直接说“把桌面的操作手册发给我”“找一下报告”“桌面有哪些文件”。唯一匹配时直接展示文件信息，再回“发送”或“发吧”；多个结果先选“第二个”或编号，再回“发送”。不再抄随机确认码，不再核对接收人 OpenID；文件默认提交给当前已授权的 QQ 对话。本机文件页只有一位已绑定接收人时自动选用本人 QQ；多位接收人时保留一次选择，避免发错对象。

仍保留首次本机账号授权及共享目录授权，连接机器人不会把陌生发信人设为主人。回复发送仅适用于当前用户刚选定的文件，2分钟有效；换请求、取消或超时清除旧选择，上传前重新核对授权和文件内容。文件改变或上传失败后不能复用旧确认，文件消息不会自动重复提交。

白话识别使用本地规则，没有接入 Agent 或 LLM，支持常见文件请求、监控状态及通知开关。例如“看看监控”“有变化告诉我”“关掉提醒”。不理解的说法会给出可用例子，不猜测执行。

### 一个按钮、一个自定义键启停

侧栏新增“鼠标工具”，设置页也提供“鼠标连点”和“图片识别点击”。连点支持固定物理像素坐标、左右键、间隔、次数、最长运行时间与延时；可以在3秒后记录鼠标位置。识图支持选择目标小图、指定屏幕范围、相似度和单次只识别不点击。目标不存在或出现多个匹配时不点击。

开始 / 停止使用**同一个按钮**，自定义启停快捷键也使用**同一个键**切换；当前支持 F2–F11，Esc 保留紧急停止。坐标、图片/区域或快捷键未设置时，任务不会启用。先“应用配置”保存参数并注册快捷键，再按该键或“开始”启动；应用配置本身不会执行点击。

修改任一参数会停止并解除快捷键，须重新应用。关闭工具、收起主窗口或退出也会停止并解除。参数保存在本机 `automation_settings.json`，下次打开恢复可编辑值，但不会自动注册快捷键、自动开始或点击。快捷键占用时给出错误且不启用任务。QQ 指令没有接入点击功能。

图片功能是同尺度图像模板匹配，不能理解按钮含义；缩放、颜色和遮挡变化会影响结果。应使用包含实际背景、文字或图案的小图，缩小识别区域，并先用单次识别检查。运行时只在内存处理指定区域图像，不落盘、不上传。每个任务均受点击次数及运行时长限制。

给定 `G:\连点器\鼠标连点器` 是 Actus 的 EXE/DLL 安装产物，没有发现可迁入源码。本次独立实现，没有复制、启动或自动控制其中的程序。

### 小窗口默认居中

所有使用统一窗口入口的设置、插件工具、通知管理、鼠标工具等自有小窗口，默认相对灵梭主窗口中心打开，并约束在主窗口所在显示器的工作区。考虑了窗口边框和标题栏；临时窗口检查中主窗口中心与两个工具窗口中心均为 `(623,476)`。负坐标显示器的定位数学有隔离测试；多显示器实机尚未验收。

- 点击测试只使用假鼠标和假 Windows API；热键测试只使用假注册/按键接口。图像验证使用合成图片，覆盖唯一匹配、多目标、不匹配、透明/纯色目标拒绝及识别过程中停止后不再点击。
- 界面检查只创建本程序的临时窗口，阻断真实输入后端、外部网络和外部进程，未启动任务或注册真实快捷键。截取的仅是这些临时窗口，不含真实 QQ 凭据或用户桌面。
- 新增依赖只装在新工程 `.venv`，固定 `numpy==2.2.6`、`opencv-python-headless==4.12.0.88`；原工程环境保持不动。

**代码完成 / 隔离验证通过**不等于真实 QQ 文件送达或真实桌面点击通过。本次没有连接真实 QQ、上传用户文件、启动游戏、点击第三方窗口、注册真实快捷键或终止已有进程。实际全局热键注册冲突、多显示器缩放、真实目标图匹配和真实文件送达仍待用户自行或另行授权验收。

## 下一步使用

1. 从旧灵梭窗口或托盘“退出灵梭”，再运行新工程 `start.bat`；旧发行包没有本次更新。
2. QQ 可发“把桌面的操作手册发给我”，根据实际回复选择并发送。没有匹配时缩短文件名关键词，检查共享范围。
3. 打开“鼠标工具”，填写目标参数，选择启停快捷键，应用配置。应用后仍不自动点击；目标界面就绪后才按该键或开始按钮。
4. 图片功能先用“只识别一次（不点击）”核对位置，再决定是否手动启动。

## 主要源码

`lingsuo/intents.py`：本地中文规则；`lingsuo/commands.py`：简化取文件上下文；`lingsuo/automation.py`：连点、图像匹配、热键和可停止线程；`lingsuo/window_layout.py`：自有窗口居中；`lingsuo/desktop.py`：用户入口与配置、单按钮启停、默认本人 QQ；`lingsuo/runtime.py`：停止任务的生命周期；帮助、依赖清单和对应测试已同步。

实现参考：[Microsoft SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)、[OpenCV 模板匹配](https://docs.opencv.org/4.13.0/d4/dc6/tutorial_py_template_matching.html)、[opencv-python-headless 固定版本](https://pypi.org/project/opencv-python-headless/4.12.0.88/)。这些说明支持实现原理，不作为实机验收凭据。
