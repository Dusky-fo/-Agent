## 本地资料与 QQ 共享怎样分开

用户确认的需求是：QQ 不能访问本地资料，软件可以读取和修改，软件再把确认的内容传给 QQ。

现在分为三种范围：

1. 程序运行数据：凭据、数据库、订阅等继续保存在程序私有目录。QQ 文件接口始终排除，资料编辑器也不开放这个目录。
2. 本地资料：设置 → 本机数据 → 授权本地资料文件夹。此范围只允许本机资料编辑器使用；即使处于原 QQ 共享目录里面，QQ 文件搜索和发送也排除它，先前准备的文件发送确认也会失效。
3. QQ 文件共享：文件页明确授权的其他目录，维持已有的确认发送流程。授权本地资料不会自动增加 QQ 共享范围。

本地资料编辑仅支持 1 MB 内 UTF-8 TXT/MD/JSON/INI/CFG/CSV/LOG 文本；不是数据库编辑器或 JSON 结构校验器。保存前核对内容版本，修改前的内容备份至程序数据目录 document-backups。外部程序已经改动的旧版本不会被静默覆盖。

转发步骤：打开本地资料 → 可修改并保存 → 选中需要的 1–2500 字文字 → 预览完整文字和接收人 → 在本机确认。没有选择文字时使用不超限的全文，超限提示手动选择，不自动截断。这里只发送文字，路径和原文件不发送；QQ 没有新增读取或修改资料的指令。

这是软件内对 QQ 通道的访问限制，本轮不修改 Windows 文件 ACL。受信 Python 插件仍可直接使用宿主账户权限读取文件，不能把这个功能当作对恶意插件的系统隔离。

## 彩虹岛怎样接入

如果只想要客户端退出或恢复时 QQ 提醒，不需要插件：

1. 在进程页刷新，找到自己运行的 LaTaleClient_x64.exe 或实际客户端文件名并勾选保存。
2. 连接自己的 QQ 机器人，本机配对本人并订阅通知。
3. 灵梭读取进程变化，形成本地事件，经通知队列发给已授权接收人。它不会替你启动、结束或重启客户端。

如果要体验插件接入机制，工程内新增了独立、未默认启用的只读包：optional_adapters/latale_readonly。

1. 插件管理 → 安装本地插件 → 选择上述目录。
2. 核对 manifest.json、plugin.py 和 process.read 声明；安装不会执行代码。
3. 审查并信任启用 → 退出灵梭 → 用 start.bat 重启。
4. 选中“彩虹岛进程状态（只读）”→ 查看工具 → 选择 latale_readonly.status，参数填 {} → 本机确认调用。
5. 工具只返回当前客户端 PID 和实例数；当前未运行就返回未运行，不会启动游戏，也不自动轮询。

这个包不包含选角色、樱桃控制、游戏内存读取、副本统计或挂机。把任意游戏目录放入插件文件夹并不会自动获得这些能力；每项都需要独立开发适配和验收。旧专项参考适配没有因此变成可用的通用游戏自动化模块。

## 如何启动和验收

如果已有灵梭在运行，先从它的托盘退出，再双击新工程 start.bat，在 Windows UAC 中确认。源码宿主仍显示 pythonw.exe。开发隔离自检/后台测试不请求提权，直接 main.py 属于开发入口；历史 EXE 不包含此次改动。

建议依次检查：进程勾选与筛选 → 外观皮肤保存并重启 → QQ 选择正确环境并连接 → 本人配对和带编号通知 → 专门测试资料目录的编辑与文字转发 → 只读插件主动调用。真实 QQ、UAC 和游戏状态仍需用户自己操作或另行授权，不用隔离测试结果冒充实机成功。
