# 真实功能引导与帮助中心：源码交付记录

日期：2026-11-01（北京时间）。工程：`G:\Ai\OH-WorkSpace\项目\灵梭Agent`。

## 已实现

- 首页默认显示真实待办：QQ 消息通道、接收人绑定、监控程序、有效文件共享目录。每项可跳转；本地监控与最近事件取自运行状态和数据库，没有产品模拟事件。
- QQ 页面集中提供官方平台入口、应用凭据说明、凭据检查、保存并连接、临时断开、本人配对、订阅管理、测试通知与历史。
- QQ 连接与本地核心独立启停；保存新凭据停止旧通道，再由用户点击连接启动。旧连接未停完时拒绝重复启动。消息通道连接成功以 SDK 的 Ready 事件为准，凭据验证通过不会冒充通道已连接。
- 本机先开启2分钟配对窗口。QQ 发“开启”只生成待确认请求，用户在本机核对相同配对码并确认后，才保存 OpenID 和通知订阅；无需手动复制身份。确认码与请求一次性，过期、取消、换凭据或断开失效；并发确认只接受一个。绑定不开放文件目录。
- 更换 AppID 必须填写对应新密钥，并撤销旧应用绑定、订阅和待发通知。界面在更换前明确提醒；同一 AppID 留空可保留已保存密钥。不同设置按段更新，避免保存监控时覆盖刚完成的接收人绑定。
- 带编号测试通知有独立记录：本机待发送、平台接受、用户确认收到。平台接受前不能标记收到；用户须核对手机相同编号后主动确认。失败、撤销授权、换应用均不能伪装为收到。
- 监控以可搜索的程序列表为主，同名程序合并显示实例数；手动文件名、检测间隔收进高级设置。暂停后保存生效。
- 文件页清楚展示授权目录、文件路径、大小和本人接收人，发送前再次确认；没有授权、没有结果或没有绑定时，给出下一步入口。
- 帮助中心提供可搜索的8个主题：首次使用、QQ 创建/凭据、配对绑定、通知与订阅、监控、文件、插件、常见问题；页面有就近帮助入口、可复制指令和官方文档链接。
- 本轮没有在产品界面加入模拟退出、模拟发送或虚构成功数据；测试替身仅存在于开发测试中。
