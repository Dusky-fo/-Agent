# 灵梭 1.0：QQ 设置及文件发送界面修正

本轮源码已写入 `G:\Ai\OH-WorkSpace\项目\灵梭Agent`。LataleGuard 仅作只读参考；未复制真实 AppID、AppSecret、OpenID、订阅或日志。未生成新 EXE 或压缩包。

## 已实现

- 总览及各页右上角显示版本 1.0。
- 监控、桌面授权、沙箱勾选统一绘制 √，不再使用会呈现 × 的原生主题指示器；支持鼠标及空格键。
- QQ 设置按原工程的字段顺序和手工 OpenID 流程迁入原生窗口：AppID、AppSecret（留空保留）、接收通知的 openid、沙箱环境、申请步骤、取消/保存。沙箱与凭据在同一个弹窗中始终可见，帮助区域独立滚动。
- 默认界面移除“开始绑定（2分钟）”和配对码页签。QQ 发“开启”仅回复发送人自己的 OpenID；必须在本机粘贴、核对和保存才授权。旧配对机制作为兼容后台代码保留，默认桌面不提供入口。
- 保存 QQ 配置不主动联网，之后使用“应用已保存配置并重连”；检查凭据是独立的真实接口操作。本轮验证均使用替身接口，没有实际请求 QQ。
- 新增接收人自动订阅；已有退订选择保留；移除身份撤销其通知和文件权限。更换机器人或环境清除旧授权与待发队列。接收人授权不开放桌面。
- 文件页按“01 授权共享范围 → 02 查找并选择文件 → 03 核对并发送”排列。共享文件夹改为紧凑下拉框，文件列表获得更多空间；可查看有效目录数、桌面位置、授权状态与文件大小限制。
- 底部固定接收人与发送入口，选中文件显示名称、大小、完整路径；仍须发送前确认。未绑定或未连接时给出操作入口。
- 桌面授权取消、保存失败或当前忙碌时恢复真实配置值，避免勾选成功但权限未保存。目录撤销与桌面开关分开控制。
- 程序内帮助及 README 已同步到当前流程。

## 验证范围

完整隔离测试共 119 项：118 通过，1 跳过。跳过项是 Windows 符号链接创建权限不足；路径越界及 junction 等其他检查保留。自检通过，报告中明确 `real_qq=false`。

界面检查只创建本程序的临时窗口，使用临时目录、空进程采集器和阻断网络/子进程的验证环境，仅截取该窗口。1150×800 和 980×700 下文件列表、勾选及发送入口可见。截图中的桌面指向已经清理的临时目录，并非用户桌面；不代表真实业务记录。

真实 QQ 收发：**未验收**。仍需用户另行授权验证应用凭据、沙箱名单与单聊权限、真实消息通道、“开启”回复 OpenID、本人授权持久化、测试通知实际到达及小文件上传。没有连接真实 QQ、上传用户文件或操作游戏。没有启动用户正在运行的桌面自动化。

## 使用当前源码

1. 从现有灵梭窗口点击“退出灵梭”，或从托盘退出；仅关闭窗口会收起到托盘。
2. 双击新工程的 `start.bat`，按已有管理员启动流程确认 UAC。
3. 检查右上角显示“版本 1.0”。旧 `release`、`dist` 内程序不包含当前修改。
4. 点击“绑定 QQ 机器人”即可打开含沙箱选项的编辑窗口；文件页查看三步布局和 √ 勾选。

本轮没有替用户关闭正在运行的旧进程，也没有将源码热加载进旧窗口。
