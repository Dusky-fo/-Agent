## 完成内容

按用户提供的旧界面截图，读取原工程 panel.html，提取并沿用原 UI 的颜色、字体、214 像素侧栏、14 像素圆角与卡片间距。界面采用同一进程内的原生控件重建，保持桌面窗口形态，不引入浏览器、WebView 或 HTTP 服务。

设置页变为三列卡片：QQ 机器人、进程监控、目录设置、接收人绑定、通知策略、插件加载、本机数据、使用帮助、高级设置。卡片摘要读取实际配置及运行状态；编辑按钮进入对应真实功能。没有迁入游戏选角、副本、樱桃、卡本检测等专用功能，也未复制原工程凭据或运行数据。

总览改为圆角待办卡片；顶部使用 QQ 通道、监控数量和接收人数状态标签；左侧导航取代原来重复的顶部页签。监控、文件、QQ、插件、帮助均应用同一深色样式。高级参数与手动添加进程位于设置卡片弹窗，帮助内容同步更新。

文件页固定底部接收人和发送按钮，小窗口中可滚动查看目录与文件，发送入口保持可见。空列表显示实际下一步操作。QQ 页面保留配对确认、订阅、测试编号与用户确认收到；不会因换界面自动授权或发送。

## 主要修改

- lingsuo/desktop_skin.py：原生侧栏、圆角卡片、按钮、状态标签、深色控件与页面容器。
- resources/latale_theme.json：直接提取的原界面样式参数，记录来源文件 SHA-256；运行时不读取原工程。
- lingsuo/desktop.py：应用布局、卡片路由、高级设置与本机数据弹窗、固定发送栏。
- resources/help.json、README.md：对应新入口的真实使用步骤。
- tests/test_desktop.py：新增卡片路由、未保存进程选择与高级参数应用检查。
