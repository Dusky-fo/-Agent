# 灵梭基础版：UI 与首次体验建议

日期：2026-11-01。后续在本工程目录继续源码开发，暂不重新打包。

## 核心建议

让用户先完成一次低门槛体验，再配置 QQ。首页围绕“下一步能做什么”，进程、文件和通知围绕任务设计，技术参数收进高级设置。

当前实现的问题：默认直接进入监控设置；程序选择虽存在但不是主入口；用户需要理解进程文件名、AppID、AppSecret 和 OpenID；文件功能首次为空时缺少连续引导；QQ 配置保存后还要退出重启。试用的最大障碍是 QQ 自建机器人的配置成本，不能单靠调整颜色解决。

本轮提供交互设计原型与实施建议，尚未将新引导接入真实运行界面。原型位于 `work/ui-proposal.html`，只使用演示数据，不连接 QQ、不读取文件、不控制进程。

## 页面组织

- 首页：首次体验入口、未完成的配置步骤、添加监控/发送文件的快捷入口，以及最近任务变化。老用户收起欢迎区。
- 进程监控：以任务列表为主，卡片展示程序、当前状态、监控开关、最近变化、通知方式。主操作为“添加监控”，打开可搜索的程序选择列表；手填进程名放次级入口。支持按程序名合并多实例展示，保留 PID 明细。
- 文件发送：上方是已授权范围，下方是文件列表与搜索；每次清楚显示文件、大小、接收人和发送结果。“添加文件夹”采用本机选择流程，避免要求新用户手填路径；第一版可以先把有效路径验证和示例补好。
- QQ 通知：把连接、身份绑定、订阅、测试和发送历史放到同一功能页。设置页只保留更底层的参数，避免来回跳转。
- 扩展插件：显示来源、版本、兼容性、所需权限、信任状态和加载结果。基础功能无需插件，首次引导不要求用户安装。
- 设置：常用开关在前；检测间隔、重试次数、文件大小、数据目录和端口收进高级选项。

## 首次使用流程

### 1. 无配置本地体验

首页提供“开始本地体验”和“直接配置”两个入口。体验使用明确标记的模拟程序事件，展示“运行→退出→本地提醒→恢复”。用户无需创建账号或开启桌面共享。演示事件与真实监控记录分开存储和显示，不能写成已实际监控。

真实本地体验作为第二入口：用户自行选择正在运行的普通程序，手动关闭后在本机看到事件。程序不擅自启动或关闭目标软件。

### 2. QQ 连接向导

依次完成：准备机器人→填写应用信息→检查连接→获取本人身份→本机确认授权→开启通知→发送测试→用户确认收到。

绑定时，待绑定身份不能直接得到文件读取权限，须由本机用户明确确认。连接成功、身份已授权、是否订阅是三个独立状态。向导自动保存已完成步骤，可退出，之后继续。

优先改进“保存后重启”的体验：先实现独立 QQ 通道启停与重新连接，保持本地监控运行；完成生命周期与并发测试后，再让“保存并连接”成为主操作。不能仅加按钮却仍暗中要求退出整个程序。

提供官方文档入口与简短中文步骤，不暗示能替用户自动注册机器人。当前用户自建 Bot 的方式仍有配置门槛。

### 3. 发一份试用文件

程序提供自己的试用文件夹和普通示例文本。用户选择该目录作为共享范围，向本人发送示例文件；不默认开放整片桌面。

流程为：选择文件→核对本人接收人→确认发送→等待结果。QQ 指令旁提供可复制示例。演示可模拟这个流程，但要始终显示“演示”，不能当成真实发送验收。

## 状态与错误反馈

通知应区分：未连接、待发送、正在提交、QQ 平台已接受、提交失败、重试已用尽。平台接受不等于手机已收到；只有用户主动确认后，向导才能标记“试用完成”。

错误提示应包含问题和可操作下一步，例如“QQ 未连接，先检查连接”“接收人未绑定，前往绑定”“文件已改变，请重新选择”。按钮有忙碌态，防重复点击；配置保存采用就近反馈，避免全局短暂提示一闪而过。

空页面分别提供对应操作：无监控→添加监控；无授权目录→选择共享范围；无通知→配置接收人并测试；无插件→说明基础功能不需要插件。

所有试用按钮可取消、引导可跳过、设置可稍后继续。新手引导在帮助或设置中可重新打开。

## 下一轮开发顺序

1. 先把首页、添加监控流程、空状态与结果反馈接入现有代码，保持核心接口兼容。
2. 加入隔离的本地演示、新手进度保存与重新进入入口。
3. 完成 QQ 通道可独立重新连接、分步绑定和测试结果回执；先模拟测试，不连接真实账号。
4. 接入试用文件夹、共享范围引导和本人确认发送。
5. 用户明确授权后，用指定测试账号完成一次真实闭环：选择程序→手动退出→QQ 收到提醒→发送示例文件。
6. 找首次接触产品的人按向导试用，记录在哪一步停住，再调整。当前阶段不加 Agent、会员计费、插件商店或重新打包。

## 验收标准

- 新用户能说清产品用途，并知道第一个按钮该点哪里。
- 不配置 QQ 也能完成本地演示，且不会误认为真实消息已送达。
- 不知道进程文件名也能添加监控；失败时清楚下一步怎么处理。
- QQ 连接、绑定、订阅和发送结果相互区分。
- 文件发送前，用户能核对授权目录、文件和本人接收人。
- 关闭引导后能继续，熟练用户不被反复打断。
