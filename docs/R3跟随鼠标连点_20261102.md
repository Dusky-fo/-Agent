# 灵梭R3：普通连点跟随鼠标

当前修订20261102-r3，界面版本仍1.0。源码在 `G:\Ai\OH-WorkSpace\项目\灵梭Agent`；原LataleGuard工程未修改，本轮不重新打包。

之前普通连点采用固定坐标模式，因此需要填写X/Y。这与用户要的跟随鼠标连点不符，本轮已修改。

## 现在的行为

- 普通连点窗口去掉X、Y和记录固定坐标按钮，卡片说明同步更新。
- 普通连点跟随鼠标当前位置：鼠标移到哪里，就在那里点击；不锁定启动时的位置，不自动把指针拉回去。
- 实际输入只发送按下/松开，不发送移动指针事件；新代码对系统部分接受按下事件的情况尝试补发松开并停止。参照[Microsoft MOUSEINPUT事件定义](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput)。
- 原来的左右键、间隔、最多次数、最长时长和启动延时仍可设置；同按钮/同自定义F2–F11键启停，Esc/角落停止保留。
- 启动软件不点击、未应用配置不启用；应用配置只注册快捷键，不点击。关闭、收起或修改参数会停止并解除启用。
- 旧配置中的普通连点X/Y被忽略，已有间隔、按键和快捷键可恢复；重新应用会保存跟随模式，不再写入旧坐标。下次启动仍不会自动连点。
- 图片识别点击继续使用目标图和识别区域，区域X/Y仍有用途；本轮没有更改识图定位行为。底层固定位置接口保留给已有内部调用，普通连点界面使用跟随模式。

## 如何使用

1. 从托盘退出旧实例，再双击工程start.bat，核对侧栏20261102-r3。
2. 工具→鼠标连点→打开。不用设置坐标，填写间隔、次数/时长，选择左键或右键。
3. 选择一个F2–F11启停键并点击应用配置；此时尚未开始点击。
4. 将鼠标移到要连点的位置，按该键开始；移动鼠标会改变点击位置，再按同一个键停止。也可用开始/停止按钮。
