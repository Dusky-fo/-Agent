# 托盘：以管理员身份重启

源码修订：`20261102-r3-tray-admin`。退出已有灵梭并通过工程 `start.bat` 重新打开一次后，托盘右键菜单将包含“以管理员身份重启”。

点击后先检查未保存内容，再请求 Windows UAC 管理员授权。取消或提交启动请求失败时，当前实例继续运行并显示原因提示。不会强制结束程序，也不会重启其他程序。

授权启动请求提交后，当前灵梭按原有流程等待后台操作结束、停用输入工具并正常退出。新实例继承当前数据目录，通过只具有等待权限的进程句柄确认旧进程退出，再申请数据目录锁、启动核心。最多等待 120 秒；无法核对或等待超时则停止新实例，避免两个核心同时读写。

源码模式复用当前工程的独立环境与启动入口，不复制用户凭据或配置；已具有管理员权限时，该菜单仍可正常重启灵梭。
