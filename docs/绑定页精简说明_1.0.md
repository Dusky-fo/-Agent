# 绑定 QQ 机器人页面精简

已直接修改灵梭Agent现有源码，版本仍为 1.0；未打包。旧 LataleGuard 工程保持只读。

绑定页直接展示 AppID、AppSecret（留空保留）、接收通知的 OpenID、沙箱选项、接入步骤及取消/保存。凭据检查、应用已保存配置并重连仍在底部，属于接入操作。无需再次打开编辑弹窗。

订阅、退订、撤销授权、测试通知与手机收件确认移到“设置 → 通知管理”的独立窗口；监控与通知历史移到“设置 → 运行记录”。它们均不再显示在绑定页下面，功能和已有数据保留。程序内帮助和 README 已同步入口。

保存不会自动连接 QQ。先保存凭据与环境，再点击“应用已保存配置并重连”；QQ 发送“开启”获取本人 OpenID，回到第三栏核对并保存。接收人授权与目录授权仍分开处理。取消更改恢复已保存值。未复制截图里的凭据或身份。

隔离验证共 120 项：119 通过，1 项因 Windows 符号链接权限不足跳过。最后的桌面回归 28 项全部通过。新增验证包括通知与记录从绑定页分离、独立窗口关闭和重复打开不会破坏状态刷新。界面截图仅来自本程序的临时配置窗口；检查了 1150×850 和 980×700 两种尺寸，输入框、沙箱与保存按钮均可见，说明区域可滚动。

没有连接真实 QQ、上传文件、操作第三方窗口、结束现有进程或生成发行包。真实 QQ 收发仍未验收。

退出当前灵梭（包含托盘），再双击新工程 start.bat，打开“绑定 QQ 机器人”查看当前页面。历史文档中的“编辑弹窗”和绑定页内通知表格是之前的布局，以本说明及当前帮助为准。
