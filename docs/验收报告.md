# 灵梭基础版验收记录

日期：2026-11-01（北京时间）。

## 代码完成

独立工程已建立。通用进程监控、QQ 接入与通知、本机文件授权/搜索/确认/上传、插件清单及信任加载、本地五页面板、托盘和构建入口已实现。没有接入 Agent、LLM、Render 或其他业务云服务。

## 模拟验证

测试使用临时配置、临时普通文件、虚构 QQ 标识、模拟进程快照和模拟 HTTP；所有测试拒绝对外 socket 连接，本机面板测试仅允许回环地址。测试结果和打包后自检报告随交付附上。

覆盖：QQ 未配置时监控启动、PID 更替、采集失败不误报、暂停、文件越界/程序数据排除、真实 Windows 目录联接越界、确认过期/单次/用户绑定、文件变化、分享撤销、结果与深度限制、订阅与队列恢复、通知合并与重试上限、消息去重、插件禁用/信任/变更/异常、参数校验、面板认证和外站 Origin 拒绝、QQ 上传校验值与分片及失败不发消息、真实 SDK 接口契约的离线替身验证。

Windows 普通符号链接测试需要额外系统权限，若环境不支持则明确跳过；另有不需该权限的目录联接测试实际覆盖同类路径越界。没有为测试申请管理员权限。

## 发行包验证

构建以新工程独立 `.venv` 为基础，依赖版本锁定。构建脚本在无源码工作目录、清除 PYTHONPATH/PYTHONHOME 的临时目录调用 EXE 的 `--self-test`。该模式不打开 UI、不采集真实进程、不连接外网。

发行目录按文件名排查配置、账号、数据库、日志、上传临时副本与专用适配；包内附 SHA-256 清单和第三方许可。文件名检查不能替代所有潜在内容的完整审计。未作代码签名。

## 真实收发尚未验证

本次没有真实 QQ 登录、真实文件上传、真实主动通知或平台权限测试。后续需由用户指定测试账号授权验收：

1. QQ 网关登录、断开与重连。
2. 获取 OpenID、加入白名单、订阅与退订。
3. 实际主动通知开关、认证权限与平台配额。
4. 小文件与超过 5MB 文件的分片发送、超时、拒绝权限和收件显示。
5. 不同 Windows 桌面重定向环境与托盘交互。
6. 可选专用适配的版本、依赖与实机状态读取。

## 实际限制

插件导入失败通过异常捕获隔离；不保证恶意、死循环或原生崩溃插件不会影响宿主。通知可能至少一次送达；响应丢失时可能重复。单次文件发送采用一次性确认、不自动重复提交消息。界面与真实 QQ 权限仍须用户验收，不能将模拟通过写成真实收发通过。
