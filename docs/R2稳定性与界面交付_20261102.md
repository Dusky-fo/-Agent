## 2. 软件层面完成

- **调度与表单统一**：工作线程和版本化快照迁到desktop_jobs；保存快照、回调动作身份、冲突资源与按钮恢复统一处理。插件配置与普通设置使用相同资源和核心设置锁，避免并发覆盖配置。帮助、记录、取消和不冲突操作保留可用。
- **记录查询**：状态、操作类型、最近1/7/30天、任务编号/结果文件名，优先需处理或全部按时间；每页30条、上下页、总数。身份过滤先于查询，QQ不能借搜索查看其他用户任务。超长查询在界面拦截，不污染周期状态读取。查询范围仍受现有记录保留策略限制，不是永久归档。
- **备份管理**：512MB容量保护继续保留；恢复记录新增核对并清理已恢复备份。只允许已恢复、原位置内容仍一致的记录，先预览再明确确认；只删该记录的私有冗余备份，不删除原文件。未恢复、冲突、撤权、备份异常拒绝；执行期间用Windows读取锁防止原件并发写入/删除。中途取消可重新核对继续，不会自动清理。
- **脱敏诊断**：设置→程序与数据位置→导出脱敏诊断，用户显式选择新文件，不覆盖已有文件、不自动上传。白名单只含版本、依赖、开关、统计；不含AppSecret/AppID/OpenID、路径、正文、数据库、签名网址或原始错误响应。
- **分离页面与控制**：新增desktop_jobs、desktop_records、desktop_qq、desktop_files、desktop_monitor；保留现有desktop_ux、desktop_permissions、desktop_services和核心模块，继续Tk/ttk与一个宿主进程，没有重建框架。build_info统一修订号。

备份清理只覆盖本机文件管理file-recovery，不清理文本编辑document-backups；未恢复的唯一副本无自动删除策略。清理完成后该记录不能再依赖已删除的冗余备份恢复，原位置文件会保留。
