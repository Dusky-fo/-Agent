日期：2026-11-01

## 交付结果

当前入口为 Tk/ttk 原生 Windows 桌面窗口，不是浏览器页面，不使用 WebView，不启动本地 HTTP 面板。首页、监控、文件、通知 / QQ、插件、设置、帮助均在本程序窗口内。

主窗口、托盘、监控、通知队列、QQ 通道在同一宿主进程内使用线程。进程采集改用 Windows Toolhelp，不再每轮启动 tasklist 子进程。源码启动脚本还避开了 Windows 虚拟环境的常驻转发进程；独立依赖环境继续有效。一个数据目录有实例锁。使用 start.bat 启动，当前宿主名称为 pythonw.exe。

关闭窗口收进同进程托盘，从托盘恢复；“退出灵梭”结束程序。托盘未就绪或失败时，窗口不会悄悄隐藏，会询问是否退出。退出等待当前界面提交的后台操作完成，再清理后台。没有启动、关闭或重启任何目标程序。普通受信插件自身仍拥有宿主权限，不能保证第三方插件不会自行创建进程。

## 已实现的桌面功能

- 首页读取实际 QQ 通道、接收人、监控配置和共享范围，每项直接跳转。
- 可搜索的真实程序列表，同名实例数、加入与移除目标、保存、暂停；未运行程序在设置中手动添加文件名。
- QQ 凭据检查、保存并连接、独立重连、临时断开。错误传递到桌面提示。仅主动点击官网按钮才打开外部浏览器。
- 本机开启两分钟配对窗口，QQ“开启”创建待确认请求。本机核对配对码后授权、保存身份并订阅。第一个发消息的人不会自动授权。
- 接收人订阅、退订、撤销；带编号测试通知区分入队、平台接受和用户确认收到；查看真实运行历史。
- 系统目录选择器显式授权共享范围；桌面单独授权。文件选择器不会自动授权目录。搜索、显示大小/路径/接收人、二次确认与两分钟时效，实际提交重新验证授权和指纹。确认取消或过期不上传。
- 插件刷新、版本/权限/状态、明确审查信任启用、禁用；重启生效说明。Python 插件不是沙箱。
- 8 篇原生帮助及功能跳转。较长的 QQ 引导和文件页提供滚动，避免小屏底部操作不可达。产品没有模拟试用按钮。

## 接下来怎样使用

1. 双击新工程 start.bat，查看原生窗口和首页待办；不要运行历史 EXE。
2. 先在监控页选一个自己常用的程序并保存，查看本机真实状态；灵梭不会替你启动或结束它。
3. 需要 QQ 时，按帮助自行创建机器人并设置凭据，等待真实连接后配对本人。
4. 先验收带编号通知，再只授权一个专门的共享目录，使用自己准备的小文件验收发送。
5. 最后检查收起、托盘恢复和退出；记录真实 QQ 平台权限/配额相关失败，不能用平台接受状态替代手机收到。
